# Swift 代码库

本目录包含 *Hello 算法* 的 Swift 语言实现。

## 环境要求

- Swift 5.7+
- Xcode 14.0+ (支持 macOS / iOS 开发)

## 运行方式

### 命令行运行

进入对应章节目录，使用 `swift` 命令直接运行：

```bash
cd chapter_stack_and_queue
swift stack.swift
```

### Xcode / Swift Playgrounds

可以直接将 `.swift` 源文件导入 Xcode Command Line Tool 工程或 Swift Playgrounds 运行。
